Download & install

Download for Chrome Download for Firefox View source

Version 2.1.0 · 48 KB per browser — ready to load, nothing to compile. Not in the stores, so the browser asks you to load it by hand once.

Chrome, Edge, Brave

  1. Unpack the ZIP
  2. Open chrome://extensions
  3. Turn on Developer mode
  4. Click Load unpacked
  5. Pick the chrome folder

Firefox

  1. Unpack the ZIP
  2. Open about:debugging
  3. Go to This Firefox
  4. Click Load Temporary Add-on
  5. Pick firefox/manifest.json
  6. Firefox forgets it on restart — load it again

Verify the download

Optional. Both archives are listed in SHA256SUMS.txt — put it next to the ZIPs and run sha256sum -c SHA256SUMS.txt.
